## 📖 Justificativa da Classificação

### 🥇 1º Lugar — Git + GitHub
Ocupou a primeira posição por ser **indispensável em qualquer projeto profissional**. Permite que várias pessoas trabalhem ao mesmo tempo sem perder arquivos, registra todo o histórico de alterações e facilita muito a entrega e o compartilhamento de projetos. É a ferramenta que todo desenvolvedor precisa dominar.

### 🥈 2º Lugar — Visual Studio Code
Ficou em segundo porque é o **ambiente principal onde escrevemos os códigos**. É leve, gratuito, funciona em qualquer computador e tem extensões para praticamente qualquer linguagem. A única limitação em relação ao primeiro lugar é que, por si só, não organiza o histórico de versões do projeto — sendo justamente combinado com o Git/GitHub na prática profissional.

### 🥉 3º Lugar — Figma
Ficou em terceiro lugar porque é **especializado em uma etapa específica**: o design visual. É excelente para criar telas e protótipos antes de programar, mas não substitui as outras duas ferramentas no processo completo de desenvolvimento. Mesmo assim, se destaca pela facilidade de uso e pela colaboração em tempo real.
